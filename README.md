# Zepto SQL Data Analysis

## Project Overview
Analysis of Zepto grocery product data using PostgreSQL.

## Tools Used
- PostgreSQL
- pgAdmin
- SQL

## Project Objectives
- Data cleaning
- Product analysis
- Discount analysis
- Revenue estimation
- Inventory analysis

## Business Questions
1. Top 10 best-value products
2. Products with high MRP but out of stock
3. Estimated revenue by category
4. Products with MRP > ₹500 and discount < 10%
5. Top 5 categories by average discount
6. Price per gram for products above 100g
7. Product weight segmentation
8. Total inventory weight by category

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- CASE
- Aggregate Functions
- UPDATE
- DELETE
- ALTER TABLE
- ROUND
